# Habena

**Take the reins of your coding agents.**

Habena is an agent harness framework in Rust: a plugin-based runtime for building and driving AI
coding agents. Everything is a plugin, in the lineage of [cordis](https://github.com/cordiverse/cordis)
and deepseek-harness.
